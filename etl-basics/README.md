# Первый ETL-пример

Мой первый ETL: данные берутся из учебного API, чистятся в pandas и
складываются в SQLite.

```
Extractor.py     -> запрос к API
Transforming.py  -> типы и заполнение пропусков медианой
Loading.py       -> запись в SQLite / Excel / CSV
Automatize.py    -> запуск всей цепочки
```

Основной проект репозитория — в корне: автоматизация отчётности
контакт-центра на реальной рабочей задаче.
